# tym.in.ua

Сайт Всеукраїнського турніру юних математиків імені професора М. Й. Ядренка.
Статичний сайт на [Astro](https://astro.build): без бази даних, PHP і адмінки, тож на сервері немає чого зламати.

## Як додати новину

Створіть файл у `src/content/posts/`. Назва файлу складається з дати і короткої латинської назви, наприклад `2026-10-01-zavdannya-2026.md`:

```markdown
---
title: "Завдання XXIV ТЮМ (2026 р.)"
date: 2026-10-01
categories: [news, matherials]
---

Текст новини. Звичайний абзац.

[Завантажити завдання (PDF)](/files/2026/tym-2026.pdf)
```

- Сторінка з'явиться за адресою `/2026/10/01/zavdannya-2026/`.
- Можливі розділи: `news` (Новини), `matherials` (Завдання), `results` (Результати), `photo` (Фотогалерея), `useful` (Корисні джерела).
- PDF-файли й фото кладіть у `public/files/<рік>/`, посилання тоді починається з `/files/<рік>/...`.
- Старі записи містять HTML. Його можна правити так само, як звичайний текст.

## Команди

Потрібен Node.js 22.23.4 або новіший (див. `.nvmrc`).

| Команда | Що робить |
| --- | --- |
| `npm run dev` | локальний перегляд з автооновленням: http://localhost:4321 |
| `npm run build` | збирає сайт у `dist/` і перевіряє, що в ньому немає спаму, PHP і зовнішніх скриптів |
| `npm run preview` | показує зібраний сайт |

## Звідки взявся контент

Одноразово імпортовано з WordPress (листопад 2026):

- `npm run import:wp` перетворює XML-експорт (`export/`, не в git) на файли в `src/content/`.
- `npm run fetch:media` завантажує фото й PDF зі старого сайту в `public/wp-content/uploads/` (за тими самими адресами) і робить мініатюри в `public/thumbs/`.

Старі адреси сторінок збережено. Переадресації з колишніх адрес налаштовано в `astro.config.mjs`.
