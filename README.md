# tym.in.ua

Сайт Всеукраїнського турніру юних математиків імені професора М. Й. Ядренка.
Статичний сайт на [Astro](https://astro.build): без бази даних, PHP і адмінки, тож на сервері немає чого зламати.

## Як додати новину

Створіть файл у `src/content/posts/`. Назва файлу складається з дати і короткої латинської назви, наприклад `2026-10-01-zavdannya-2026.md`:

```markdown
---
title: "Завдання XXIV ТЮМ (2026 р.)"
date: 2026-10-01
categories: [news, matherials]
---

Текст новини. Звичайний абзац.

[Завантажити завдання (PDF)](/files/2026/tym-2026.pdf)
```

- Сторінка з'явиться за адресою `/2026/10/01/zavdannya-2026/`.
- Можливі розділи: `news` (Новини), `matherials` (Завдання), `results` (Результати), `photo` (Фотогалерея), `useful` (Корисні джерела).
- PDF-файли й фото кладіть у `public/files/<рік>/`, посилання тоді починається з `/files/<рік>/...`.
- Старі записи містять HTML. Його можна правити так само, як звичайний текст.

## Як додати фотогалерею

1. Покладіть фото (jpg або png) в окрему папку, наприклад `public/files/2026/final/`.
2. Виконайте `npm run gallery -- public/files/2026/final`. Команда зробить мініатюри в `public/thumbs/` і надрукує розмітку `<div class="gallery">…</div>`.
3. Вставте цю розмітку в текст запису. Фото відкриваються на весь екран, гортати можна стрілками.

## Переадресації

Якщо адреса сторінки змінилася, додайте пару `"стара адреса": "нова адреса"` у `src/data/redirects.json`.

## Команди

Потрібен Node.js 22.23.4 або новіший (див. `.nvmrc`).

| Команда | Що робить |
| --- | --- |
| `npm run dev` | локальний перегляд з автооновленням: http://localhost:4321 |
| `npm run build` | збирає сайт у `dist/` і перевіряє, що в ньому немає спаму, PHP і зовнішніх скриптів |
| `npm run preview` | показує зібраний сайт |
| `npm run gallery` | без параметрів створює мініатюри, яких бракує, для всіх наявних галерей |

Після пушу в гілку `main` GitHub Actions збирає сайт і публікує його на https://tym.in.ua.

## Структура

- `src/content/posts/`: записи (новини, завдання, результати, фото, корисні джерела).
- `src/content/pages/`: сторінки «Про турнір» (`home.md`), «Правила», «Організатори і журі».
- `src/pages/`, `src/layouts/`, `src/components/`, `src/styles/`: шаблони й оформлення.
- `public/wp-content/uploads/`: файли, перенесені зі старого сайту. Шляхи збережено, щоб старі посилання на PDF працювали.
- `public/files/`: нові файли.
- `design/emblema.png`: оригінал емблеми, з якого зроблено `public/emblem.webp`, іконки й `og-image.png`.
